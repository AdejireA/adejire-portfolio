# Adejire Adegite — Portfolio

A personal portfolio for work and learning across embedded systems, robotics, and autonomous systems.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run lint
```

## Content notes

- Project summaries and evaluation figures are based on the current project records and should be checked against each repository before publication.
- Writing and talks pages are intentionally honest placeholders until public entries are ready.
- The site uses a dark, text-first layout with a restrained copper accent. Most project details expand inline instead of appearing in large cards.
